Vrate adalah aplikasi berbasis web dan browser extension untuk membantu pengguna melacak film dan anime yang sedang ditonton secara otomatis. Vrate dapat mendeteksi judul serta episode yang sedang diputar, memperbarui progres tontonan ke dashboard, menyimpan film atau anime ke watchlist, dan menampilkan daftar Continue Watching agar pengguna dapat melanjutkan tontonan dengan mudah. Vrate dikembangkan menggunakan Next.js, Supabase, TypeScript, TMDB, dan AniList API, dengan fokus pada pengalaman pengguna yang praktis, modern, dan terintegrasi.
